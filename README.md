# CamSlots 배포

SketchUp 카메라 슬롯 확장 프로그램의 설치 파일과 업데이트를 제공합니다.

[최신 버전 다운로드](https://github.com/sinjiho9411-afk/CamSlots-Releases/releases/latest)

## 설치

기존 사용자는 CamSlots_v3.6.6.rbz를 확장 프로그램 관리자에서 한 번 설치한 뒤 SketchUp을 재시작해 주세요.
이후 버전부터는 패널 맨 아래 **업데이트 · 지원 → 업데이트 확인 → 업데이트 설치**를 사용합니다.
설치 완료 후 작업을 저장하고 SketchUp을 재시작하면 새 버전이 적용됩니다.

[버그 제보 — 카카오 오픈채팅](https://open.kakao.com/o/sOKmmGYh)

## 새 릴리즈 게시 규칙

- 태그: `v3.6.7`처럼 `v숫자.숫자.숫자`
- 첨부 파일: 내부 버전이 같은 `CamSlots_v3.6.7.rbz` 한 개
- 정식 릴리즈로 게시하고 Latest로 지정
- 변경 내용은 릴리즈 본문에 작성
- GitHub가 생성하는 SHA-256 digest로 클라이언트가 검증하므로 별도 체크섬 파일 불필요
- 새 배포마다 버전 증가. 같은 버전 파일 교체는 자동 업데이트로 감지하지 않음

macOS SketchUp 26.1.257에서 실제 다운로드·설치·완전 재시작 후 적용을 확인했습니다.
Windows 및 구형 SketchUp 실기 검증은 미실시입니다.
